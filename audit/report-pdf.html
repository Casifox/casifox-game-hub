Détail des deux corrections prioritaires

Neon Jackpot — BUG-incremental-002 (CRITIQUE)

Fichiers : src/js/state.js (import, lignes 324–332), src/js/pages.js (rendu du journal et des effets, lignes 167, 210, 632), src/js/utils.js (fusion, lignes 147–164).
Constat : une sauvegarde importée n'est contrôlée que sur un champ (tokens). Les champs journal[].icon et buffs[].icon/value sont ensuite insérés tels quels dans la page. Test : un fichier contenant <img src=x onerror="…"> fait exécuter le script (vérifié).
Pourquoi c'est critique : l'origine casifox.github.io est partagée par tous vos projets publiés. Un script exécuté dans Neon Jackpot peut lire les sauvegardes des autres jeux du même domaine.
Correction : valider le schéma de la sauvegarde à l'import et au chargement (types, longueurs, liste blanche pour les icônes, valeur numérique) ; échapper tous les champs affichés ; ne pas copier les tableaux sans contrôle.
Vérification : rejouer T-INCR-02 : le script ne doit plus s'exécuter.

Neon Jackpot — BUG-incremental-001 (MAJEURE)

Fichiers : src/js/state.js (chargement 262–275, sauvegarde 284–299), src/js/main.js (sauvegarde automatique, 120–123).
Constat : une sauvegarde illisible (JSON invalide) est remplacée par une partie neuve dans les premières secondes, sans conserver la valeur d'origine.
Correction : avant la première écriture, copier la valeur brute sous neon_jackpot_save_v1.backup.<date> et prévenir le joueur.
Vérification : rejouer T-INCR-01 : une clé de secours doit apparaître.

AVANT LE SILENCE — BUG-avant-le-silence-001 (MAJEURE)

Fichiers : js/storage/save-manager.js (lecture 28–39), js/core/state-manager.js (chargement 22–31, écriture 74).
Constat : la valeur illisible reste en place jusqu'à la première action du joueur, puis est remplacée par une progression neuve, sans copie.
Prérequis : le projet n'a pas de dépôt Git. Décider d'initialiser un dépôt local avant de modifier (traçabilité et retour arrière).
Correction : copier la valeur brute sous avant-le-silence.save.v1.backup.<date> avant tout écrasement.
Vérification : rejouer T-AVANT-01 : une copie de secours doit apparaître.
